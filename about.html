AI assistance AI 協助說明

The code for this website (page layout, styles and the script that turns the record sheet into the pages) was written with help from an AI coding assistant, Claude Code (Anthropic). The course teacher allowed AI help for the project, and it is declared in the Honour Declaration.

The test results, the readings of 箋校 and 唐人行第録, and the verdicts are the student's own. The AI being tested is a separate model, named on the Method page. The site's git history records which changes were AI-assisted.

Privacy 隱私

No login, no cookies, no analytics and no tracking. The pages are static files on GitHub Pages. Fonts load from Google Fonts, which receives your IP address as any web server would. If you switch between light and dark themes, that choice is saved in your own browser only.

How to cite this site 引用本站

Zhang, H. (2026). Identifying Bai Juyi's friends with AI and historical sources [Website]. https://hanbin2007.github.io/bai-juyi-friends/

To link to a single entry, add its number, e.g. …/bai-juyi-friends/#r9 for 楊八.
